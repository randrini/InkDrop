v0.1.10 — since v0.1.09

**Acquisition & matching**
- Fixed manga/comic classification reverting on every library sync — it's now self-correcting and manual corrections persist
- Fixed a MangaDex regression that could stop new chapters of an ongoing series from being tracked
- Fixed Edition Indifferent and the Monitored / Auto-Grab toggles silently turning back on when a request sent "false" as a string instead of a real boolean
- Fixed a provider-key mismatch that could permanently block an item from reaching Awaiting Release
- Every enabled provider now has to complete a clean pass before an item is marked Awaiting Release
- Fixed queue items getting stuck on "Importing" indefinitely after the transfer had actually finished
- Fixed manga volume/chapter imports silently stalling in operator review; ambiguous units now surface clearly in Manual Review
- Acquisition self-healing now caps stall-retries into Manual Review, and moves genuinely unavailable items to Awaiting-Release instead of retrying forever
- Reject fractional-issue matches when the want is for a whole number; reject numbered wrong-subseries SLSKD candidates
- Source-worker selection now respects Indexer Download Priority
- Added a cooldown for SLSKD searches that come back empty or thin, and reserved every source lane a minimum runtime budget so none gets starved out
- Normalized "&" vs "and" spelling differences across title matching; recognize volume ranges written with a tilde, ampersand, or repeated marker
- Manga acquisition now prefers same-tier official English publishers when choosing between candidates
- Stop treating a renamed series folder as a lost download; stop two folders tying and deciding where a series lives unpredictably
- Guard MangaDex discovery-only companions from being removed or re-parked by a routine sync
- Added a per-series Edition Indifferent override for collected-singleton matching
- Show real SLSKD peer availability instead of a hardcoded "Unavailable"

**Prowlarr, direct download & metadata sources**
- Prowlarr requests now send the API key in the header only by default, not as a URL query parameter — keeps it out of proxy and access logs (an off-by-default fallback setting exists for proxies that strip custom headers)
- Fixed Prowlarr requests hitting the wrong endpoint when base_url omits /api/v1
- Prowlarr health checks no longer swallow non-JSON responses — failures are actionable now
- Fixed the self-healing sweep not recognizing Prowlarr's child indexers, which could leave an item searching through them forever without ever building a clean streak
- Wired the Cloudflare-bypass proxy into Buzzheavier, ComicsCodes, and GetComics; hardened bypass verdict handling
- Made the Cloudflare-bypass proxy and Prowlarr's /api/v1 setting easier to find in Settings
- Added Metron as an optional fallback comic metadata source; fixed pagination and issue-catalog accuracy gaps

**History & reliability**
- Fixed History rows losing their expand/detail control at mobile widths
- Fixed Core Overview showing a false "0" for History instead of omitting the tile when the count wasn't available
- Fixed History losing track of an item's wanted/issue record after a duplicate-series merge
- Added an Acquisition Reliability view: per-item lifecycle tracking with live rollup buckets
- Added Recovery controls: retry with another source, block a release, or reopen a stuck import
- History now caches its per-request event count and lets a row's series link through correctly

**Backup & settings**
- Backup-import preview now uses bounded, indexed lookups instead of one growing in-memory index — previewing a large library's backup dropped from roughly two minutes to about a second
- Added a full-backup import/restore workflow with a safety preview step. Live one-click restore-apply stays temporarily disabled while a data-safety gap in that specific path is closed — creating, downloading, and previewing backups all work normally
- Reclaimed dead SQLite pages automatically; added a configurable cap on how many full backups to keep
- Closed resource-exhaustion gaps in backup-archive handling, and fixed the aggregate size cap wrongly rejecting legitimate large backups
- Fixed Library Paths and Manual Inbox settings not always saving to where the rest of the app reads them from
- Fixed a Download Clients settings bug that could nest a client's config inside itself
- Added opt-in hardlink placement for unmodified import files
- Added PUID/PGID support to the Docker image (opt-in)

**Interface**
- Added Pull List: a week-boxed view of what's publishing for the series you follow
- Added a lightweight mobile status view at /m; fixed it blocking first-run setup and flapping between / and /m
- Fixed Issues row actions overflowing off-screen at desktop widths
- Fixed Downloads timing out, Queue's masthead counts zeroing out, ambiguous Wanted attention counts, and Series not reloading
- Fixed Series back-navigation losing scroll position, Manual Review's count mismatching its list, and a double-click race on Queue details
- Finished Komga reader-sync: identity-aware visibility with live library discovery

**Security & data integrity**
- Fixed a duplicate-series-merge bug where merging two series could leave issue and collection records pointing at the wrong series afterward
- Stopped API keys from leaking into logs and error text in more places, including provider health checks and SABnzbd error messages
- Fixed a data-corruption bug in identity-collision handling during file repair
- Fixed a crash during full-state sync on certain media file records
- Fixed a silent state-database restore failure after a stale write-ahead-log replay
- Schema upgrades can no longer reverse a user's series removal
- Closed a diagnostics-endpoint information leak and an authentication-method exclusivity gap
- Fixed a settings cache that could serve stale data right after a change was saved
- Guarded against duplicate "import verified" notifications, and against losing a notification to a timestamp tie or a failed write
